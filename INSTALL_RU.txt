УСТАНОВКА PWA «МОЯ КНИГА РЕЦЕПТОВ»

1. Бесплатное размещение на GitHub Pages

1) Создайте аккаунт на https://github.com, если его ещё нет.
2) Нажмите New repository.
3) Назовите репозиторий, например cookbook.
4) Выберите Public и нажмите Create repository.
5) Распакуйте personal_cookbook_pwa.zip.
6) На странице репозитория нажмите Add file → Upload files.
7) Загрузите в корень репозитория:
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - README.txt
   - INSTALL_RU.txt
   - папку icons со всеми PNG-файлами.
8) Нажмите Commit changes.
9) Откройте Settings → Pages.
10) В разделе Build and deployment выберите:
    Source: Deploy from a branch
    Branch: main
    Folder: / (root)
11) Нажмите Save.
12) После публикации адрес обычно будет таким:
    https://ВАШ-ЛОГИН.github.io/cookbook/

2. Установка на iPhone или iPad

1) Откройте опубликованный адрес в Safari.
2) Подождите, пока книга полностью загрузится.
3) Нажмите «Поделиться».
4) Выберите «На экран Домой».
5) Убедитесь, что включено «Открывать как веб-приложение», если этот переключатель отображается.
6) Нажмите «Добавить».
7) Запустите книгу с появившейся иконки «Моя кухня».
8) После первого успешного запуска откройте несколько вкладок приложения, затем проверьте работу без интернета, временно включив авиарежим.

3. Сохранение данных

Меню, покупки, избранное и отметки сохраняются локально в хранилище приложения на конкретном устройстве.
Обычное закрытие приложения данные не удаляет.
Данные могут исчезнуть при удалении веб-приложения, очистке данных Safari/сайта или смене адреса публикации.
Синхронизации между iPhone и iPad в этой версии нет.

4. Обновление книги

1) Замените файлы в репозитории GitHub новыми версиями.
2) В service-worker.js измените CACHE_NAME, например cookbook-pwa-v1 на cookbook-pwa-v2.
3) Сделайте Commit changes.
4) Откройте приложение при наличии интернета.
5) Если старая версия осталась в кэше, закройте приложение и запустите снова.

Важно: не открывайте index.html напрямую из приложения «Файлы» для установки PWA. Service worker требует публикации через HTTPS.
